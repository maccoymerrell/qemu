# ADJUDICATED OPCODE-CLASS TRANSITIONS -- the transitions a maintainer has
# ruled may happen, read by opcenc_loss_gate.sh / opcenc_ab.py.
#
#   <isa> <encoding-hex> <A_CLASS> <B_CLASS>   # reason
#
# The A and B classes are BOTH named, so a row amnesties one exact transition
# and nothing else: a ledger keyed on the encoding alone would silently cover
# a second, different move on the same bytes later.
#
# A row here is counted, printed and excluded from the bar.  A PENDING row
# whose subject the measurement does not contain is STALE and FAILS the gate
# -- a ledger that outlives its subject is how a gate quietly stops gating --
# so a transition that has landed is PROMOTED to a LANDED row below, never
# left as a PENDING one and never left as a comment.
#
# An entry with no reason is refused at parse time.  "It was already like
# that" is not a reason; name the ruling or the measurement.
#
# TWO ROW KINDS, and the difference is whether the row must have a subject.
#
#   <isa> <enc> <A> <B>          # reason   PENDING -- a transition between
#                                the two arms of a comparison being run NOW.
#                                It MUST appear in that measurement; a
#                                PENDING row matching nothing is STALE and
#                                fails, and once the change is the tip the
#                                row is retired or promoted to LANDED.
#
#   LANDED <isa> <enc> <A> <B>   # reason   LANDED -- a transition that is
#                                ALREADY on the wire.  Exempt from the stale
#                                rule, because an A/A run at the tip contains
#                                none of them and a cross-tip A/B against an
#                                older arm contains all of them, and both are
#                                legitimate runs of this gate.
#
# WHY THE LANDED SECTION EXISTS.  Without it, every A/B that reached across
# #333's admission or the PREFETCH repair re-litigated the same thirty-three
# transitions by hand, in a wave-local file that died with the wave -- which
# is how one ruling gets decided two different ways.  A ruling is written
# once and read here.
#
# AND IT CANNOT AMNESTY A REGRESSION.  A row names BOTH classes, so `A -> B`
# says nothing about `B -> A`: a change that put a landed transition back the
# way it was is a different key, is unadjudicated, and fails.  The
# instrument's H3 selftest arm is exactly that case.
#
# THE PENDING SECTION IS EMPTY BY DESIGN at the tip: the two arms of a no-op
# comparison publish the same class for every encoding, and every PENDING row
# added here is a wire change somebody has to have ruled.

# ==========================================================================
# LANDED -- on the wire at the tip.  Read on any A/B that reaches across the
# commit named in the reason; never required to have a subject.
# ==========================================================================
