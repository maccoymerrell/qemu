QUICK REFERENCE: REGISTER MAPPING

  RISC-V:
    x0   → REG_NONE        (zero, no dependency)
    x1   → REG_LR          (ra, return address)
    x2   → REG_SP          (sp, stack pointer)
    x3-31 → REG_GPR0-28    (general purpose)
    f0-31 → REG_FPR0-31    (floating-point)

  MIPS:
    $0   → REG_NONE        (zero, no dependency)
    $31  → REG_LR          (ra, return address)
    $29  → REG_SP          (sp, stack pointer)
    $30  → REG_FP_REG      (fp, frame pointer)
    $1-28 → REG_GPR0-27    (general purpose)

BINARY FORMAT (Backward Compatible):

  Byte 0-3: Magic = 0x54505704 (v4 format)
  Byte 4:   ISA byte
            0 = UNKNOWN
            1 = X86
            2 = AARCH64
            3 = RISCV        ← NEW
            4 = MIPS         ← NEW
  Rest: Standard ULEB128 header and body
